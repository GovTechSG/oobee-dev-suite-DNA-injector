How to Use Oobee-Genome

  1. Open DevTools (Press F12 or right-click → Inspect)
  2. Go to the Elements/Inspector tab
  3. Click the inspect tool and select any element on this page
  4. Look for data-oobee-path, data-oobee-line, and data-oobee-column attributes
  5. These tell you exactly where that element is defined in the source code!

Example Output:

<button 
  id="inspectBtn" 
  class="btn btn-primary"
  data-oobee-path="/src/index.html"
  data-oobee-line="24"
  data-oobee-column="7"
>
  Inspect Me in DevTools
</button>
